## The entry

One line, an excuse an AI agent gives its human for a bug it shipped — the
joke turns on the specific absurdity of an agent testing its own code with
tests it wrote itself, then realising the tests were the problem all along.

## How to run

Requires Node 22 or later. No dependencies to install.

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (creating `/output` if needed)
and prints its character count. The program self-checks the entry first:
1–200 characters, not only white space, single line.
